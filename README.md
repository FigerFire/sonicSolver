# SonicSolver solver sources

This repository contains the `src/solver` subtree exported from SonicSolver on 2026-09-14.

The source layout is preserved as `src/solver`. These solver sources are part of the larger SonicSolver codebase and depend on project modules outside this export, including `src/core`, `src/methods`, `src/models`, and `src/infrastructure`. It is therefore a source-only extraction and is not independently buildable.
